# BookShelf

BookShelf is a mini fullstack library application built with React, Go and PostgreSQL.

The project is currently in progress.

## Abstract

BookShelf will allow users to search books through Open Library API and save selected books into a personal library.

At the current stage, the project is focused on setting up the base architecture, frontend structure, backend structure and first API endpoints.

## Tech Stack
